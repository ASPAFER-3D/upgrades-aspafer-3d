## Sobre

Este repositório centraliza todos os projetos de código desenvolvidos com Claude para a ASPAFER-3D, permitindo:

- **Backup** seguro no GitHub
- **Histórico** de versões e evolução do código
- **Colaboração** aprimorada com o Claude em sessões futuras
- **Organização** clara por projeto e versão

## Uso com Claude

Para continuar o desenvolvimento de qualquer projeto com Claude, basta referenciar o diretório correspondente neste repositório. O histórico de commits e o código existente servirão de contexto para o assistente.
